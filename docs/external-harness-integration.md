# T2 Code / Hermes Agent から選ぶ軽量機能

## 目的

DSH の Web 画面に、他のハーネスの便利な操作を少しずつ追加する。初回は既存の DSH セッション、入力欄、`AGENTS.md` の仕組みを使い、新しいエージェント実行環境や常駐サービスを増やさない。

参照元は [T2 Code](https://github.com/ashutoshpw/t2code) と [Hermes Agent](https://github.com/NousResearch/hermes-agent)。どちらも MIT ライセンス。今回はアイデアを参照して独立に実装しており、ソースコードを複製していない。

## 今回の追加機能

| 元の着想 | DSH での機能 | 起動時負荷と境界 |
| --- | --- | --- |
| T2 Code の prompt links | 現在のセッションと下書きを URL で共有。開いた側が明示的に下書きへ取り込む | 既存の `inputActions.setDraft` を使用。送信、権限変更、外部接続はしない。常駐処理なし |
| Hermes の persistent memory | 任意の `dsh-bounded-memory` パッケージ。明示的に記憶・削除を依頼された内容だけを保存 | DSH が新規セッションで読む `$DSH_HOME/AGENTS.md` に有界な管理区画を投影。別サービスや自動圧縮なし |

共有する下書きは最大 8,000 文字。URL の `prompt` パラメータは読み込み後に取り除き、非表示文字を除去してから表示する。URL は秘密情報の共有手段ではない。

メモリはユーザー設定が最大 1,375 文字、作業上の事実が最大 2,200 文字。上限超過で自動削除はしない。保存データと `AGENTS.md` の管理区画が食い違う場合は編集を止め、黙って上書きしない。任意パッケージなので、モバイルプラグインだけを導入してもメモリ機能は追加されない。

## 今回含めないもの

T2 Code の独立した認証・RPC・エージェント操作、Hermes の Python ランタイム・gateway・音声・ブラウザー・自動化は取り込まない。DSH の既存のモデル選択、セッション、スキル、MCP、承認、差分表示も複製しない。次の機能は、実際の利用上の不足と起動時負荷を確認してから個別に選ぶ。

## 検証と適用

コードの機能テストはプロンプトリンクの取り込み・明示操作・コピーと、メモリの保存・削除・上限・既存 `AGENTS.md` 保全を確認する。iPad 幅ではサイドバーがチャットに重ならず、明示的に閉じるまで開いたままかを確認する。

稼働中 DSH への適用と画面上の確認は別工程。プロファイルの変更と再起動は、実行中のセッションを確認してから行う。公開フォークのコードは、実機の適用済み状態と区別して記録する。
