# dsh-bounded-memory

Hermes Agent の有界な永続メモリを参考にした、DSH 用の小さな任意プラグインです。追加のサービスや常時ポーリングはありません。DSH が既に読む `$DSH_HOME/AGENTS.md` に、プラグイン所有の短いセクションだけを追加します。内容は次に開始するセッションから有効です。

`bounded_memory` ツールは `read`、`add`、`remove` に対応します。保存はユーザーから明示的に記憶を依頼されたときだけ行う設計です。ユーザーの好みは 1,375 文字、作業上の事実は 2,200 文字まで。上限に達するとエラーを返し、古い内容を自動で捨てません。

保存元は `$DSH_HOME/memories/bounded-memory.json` です。`AGENTS.md` の管理ブロック以外は保持します。パッケージや GitHub フォークにメモリ内容は含まれません。

導入する場合は、このパッケージを DSH プロファイルの依存関係と bundle 一覧へ追加し、DSH を再起動します。稼働中の作業がある場合は終了・中断の状態を確認してください。
